This is a simple GitHub pages page (<https://tom-fibo.github.io/PascalTriangleColor/>) that displays a large Pascal's Triangle, where each cell is colored by its remainder by various numbers (I've heard it known that doing this mod 2, i.e. coloring odd cells and not even cells, approximates Sierpinski's Triangle, and wanted to try with other numbers).

Years ago, I created a Java program to do this, however I wanted to share it with others in a simple webpage so I vibecoded a simple webpage version.
